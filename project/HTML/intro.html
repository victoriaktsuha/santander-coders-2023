Front-End

Parte visual da aplicação composta por linguagem (de marcação, não programação) HTML (estrutura), CSS (estilização) e JavaScript (funcionalidade)

A web pode ser considerada, na semiotica, um unico hipertexto ( <mark></mark> ) (texto que navega para outros textos)

Linguagem de marcação ( <strong></strong> ) possui simbolos ( <code></code> ) especiais que indicam metainformações, referindo-se a forma, hierarquia ( <s></s> ), ordem e/ou semantica ( <em></em> ) dos elementos da pagina. (<b></b> ≠ <strong></strong>)

"Marcação -> tags" ( <blockquote></blockquote> ) 

Tags podem ter atributos (chave-valor)  ( <pre></pre> )
